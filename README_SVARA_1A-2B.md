# SVARA: voice-guided form filling (modules 1A to 2B)

SVARA lets people fill in forms (hospital registration, government schemes) by **speaking** in Malayalam, Kannada,
Hindi or English. This package contains everything built so far **from 1A to 2B**, tested and documented.

## Status

| Module | What it does | In this zip |
|---|---|---|
| **1A** `audio_io.py` | Load audio (file / upload / mic) -> mono, 16 kHz, normalised | yes |
| **1B** `preprocess.py` | Pre-emphasis, 300-3400 Hz band-pass, noise reduction, VAD trimming | yes |
| **1C** `features.py`, `plots.py`, `evaluate.py` | Features (MFCC, pitch, ...), before/after plots, WER-vs-SNR experiment | **NO** (lives in the team's git repo, commit `d2a0c70`) |
| **2A** `stt.py` | Speech-to-text: cloud API + local Whisper fallback, language ID | yes |
| **2B** `extractor.py`, `lexicon.py`, `normalizers.py` | Field extraction (numbers, dates, names ...), confirmation logic | yes |
| 2C | Text-to-speech (gTTS) and the official WER function | not built yet |
| 3A / 3B / 3C | Full Streamlit app, dashboards, integration, slides | not built yet |

`scripts/try_it_app.py` is a **test page** for 1A + 1B + 2A + 2B (record or upload a voice, see the cleaned audio,
the transcript, the extracted field and a confirmation reply). It is not the final app (that is 3A).

## Setup (Windows PowerShell; Linux/macOS: use `python3` and `source .venv/bin/activate`)

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python stt.py --download          # once: the local Whisper model (~460 MB); needs internet
```
Optional: `ffmpeg` (only to read WebM / M4A files). Optional cloud features: copy `.env.example` to `.env` and put a
`GROQ_API_KEY` in it. **Never commit `.env`** (it is in `.gitignore`).

## Run

```powershell
python -m pytest -q                         # all tests; no network needed
streamlit run scripts/try_it_app.py         # the test page
python scripts/e2e_check.py                 # command-line check of 1A + 1B on one recording
python stt.py clip.wav                      # speech-to-text on a file
python extractor.py "I am twenty five years old" --field age
python extractor.py "no, say again" --confirm --field age
python scripts/eval_extractor.py            # 2B accuracy report on the labelled cases
```

## How the modules connect

```python
from audio_io import load_audio                         # 1A
from preprocess import clean_audio                      # 1B
from stt import transcribe                              # 2A
from extractor import extract_field_full, handle_confirmation, spoken_form    # 2B

cleaned = clean_audio("answer.wav")                     # mono, 16 kHz, cleaned
text, lang = transcribe(cleaned, language="hi")         # "मेरी उम्र पैंतालीस साल है", "hi"
r = extract_field_full(text, "age", language=lang)      # r.value == "45", r.status, r.issues ...
# ... read back with text-to-speech (2C), then:
o = handle_confirmation(reply_text, "age", language=lang)   # accept / update / reask_field / ...
```

## Important findings (details in `docs/`)

* **Whisper cannot transcribe Malayalam** (stock models, any size, local or cloud): measured on real speech. A
  Malayalam fine-tuned model works (`SVARA_WHISPER_MODEL_ML`, about 3 GB, opt-in). Kannada needs the large cloud model.
  English and Hindi work well with the local `small` model. See `docs/2A_Speech_to_Text.docx`.
* In a first preview, the 1B band-pass **hurt** Whisper on clean read speech; test each stage on your own data
  (1C's experiment). See `docs/2A_Speech_to_Text.docx`, section 5.1.
* The 2B rules were tested on **hand-written** examples, not real recogniser output. Add real transcripts to
  `tests/data/extractor_cases.csv` and re-run `scripts/eval_extractor.py`. See `docs/2B_Field_Extraction.docx`.
* The cloud engine (2A) and the LLM helper (2B) were tested against mock servers only; try them once with a real key.
